# P1-M13 GST — implementation checkpoint

**Status: partial GST workspace only. Not complete, migrated, built, tested, or filing-ready.**

## Implemented

- GST workspace derives totals only from persisted M10 `Posted` invoice documents and their immutable line snapshots.
- Missing GSTIN, place of supply, invalid invoice number, missing required IRN and missing HSN are surfaced as blocking exceptions.
- Branch-scope filtering is applied to workspace/export; only all-tenant scope can file the tenant-wide GST period.
- Exception-review notes, period filing status and a filing snapshot are persisted. Filed months reject exception-review edits.
- Internal JSON export is explicitly identified as unvalidated and excludes unsupported portal sections rather than inventing data.
- GST API, route `/m13/gst`, navigation, responsive workspace, and basic Angular/domain test sources added.
- M03 remains the source for effective-dated tax rates; no duplicate GST rate master created.

## Not covered / blockers

M10 invoices cannot yet post; no live sales tax rows are available. GSTR-1 B2B/B2CL/B2CS/notes/HSN/document-series schema and Excel exports are incomplete. GSTR-3B does not tie to M12; supplier ITC, 180-day reversals, RCM, e-invoice/e-way registers, statutory HSN-digit configuration, rate-change approval log, audit of exception reviews, permission-scoped filing unlock, and historical document lock enforcement are pending. External filing is manual and not represented as a successful provider integration.

No EF migration/model snapshot or executed tests exist. SQL package `database/scripts/P1-M13/` is draft only; do not deploy.
