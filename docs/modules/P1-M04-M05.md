# P1-M04 CRM and P1-M05 Quotations

**Scope:** M04 CRM/enquiries and M05 quotations only. M06 sales orders are not implemented by this delivery. Tenant authentication, RBAC, module-entitlement enforcement, SaaS licence policy and the Carbon & Copper shell remain shared platform responsibilities and are reused unchanged.

## Status and acceptance basis

This guide records the current implementation and the verification performed for the local source tree. A code path is not considered accepted solely because its route or screen exists. PostgreSQL deployment, provider delivery, browser UAT and M06 integrations are external/manual evidence gates.
