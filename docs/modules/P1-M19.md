# P1-M19 Quality samples and disputes — implementation checkpoint

Updated 2026-11-27. **Status: PARTIAL.** This source implementation is not a claim of full BRD acceptance, deployed schema, or UAT readiness.

## Implemented in this checkpoint

- Tenant-owned M19 criteria, sample, scheduled-test/result, dispute, dispute-invoice/evidence, and immutable event entities. EF uses the existing tenant query-filter and write-boundary conventions.
- `M19Rules` computes due dates and pass/fail only against an explicitly configured grade criterion; absent criteria produce `ReviewRequired`, never an assumed threshold.
- `M19Endpoints` is registered in `Program.cs` at `/api/v1/m19`. It provides completed-trip sample options, sample creation, 7/28-day concrete schedules, effective-dated criteria, result entry/correction, linked dispute creation/status transitions, invoice holds, audit history, report summaries, M18 evidence linking, and owner reminder refresh.
- API calls enforce the M19 module entitlement, endpoint permissions, tenant filtering, branch/plant/own scopes, row versions for results/disputes, and unique client idempotency keys for sample/dispute creation. M18 attachment references are accepted only when current, clean-scanned, available, and linked to the same trip.
- Failed 28-day tests create a linked quality dispute, hold posted invoices that reference the trip/order, write M10 invoice events, and create in-app notifications for users assigned the dispute-resolution permission. `M02Notification` is used; no external channel delivery is claimed.
- Angular `/m19/quality` is guarded by module/permission checks and linked in navigation. It calls M19 endpoints for trips, samples, tests, criteria, disputes, history, reports, and due-reminder refresh. It uses Carbon & Copper tokens, loading/empty/error/success states, and server-confirmed writes.
- Unit and UI tests cover no-threshold review state, acceptance evaluation, date/criteria validation, sample status aggregation, real API endpoint wiring and failure messaging.
