# P1-M15 Dashboard and Home — implementation checkpoint

**Status: partial transaction-backed dashboard. Not complete, migrated, built, or tested.**

## Implemented

- `/api/v1/m15/home` returns order count/value, posted invoice value, posted allocation estimate, trip counts/status quantities, unbilled challan count, M14 posted expense total when `global.view_cost` scope intersects, and pending work counts.
- Metrics query persisted source records; tenant filtering is provided by the existing DbContext, and branch/own scope is applied per source query.
- Cards linking to the corresponding worklists, date filters, responsive layout, optional-module/permission gating and test source.
- Unsupported cash/bank, payables, profit, trends and other missing source integrations are explicitly returned as unavailable.

## Not covered

No role-specific owner/sales/ops/purchase/accounts/driver compositions, saved card configuration, list ranking/urgency, previous-period trend, auto-refresh, setup checklist, real-time read model, ≤3s/4G validation, or automated report tie-out. Outstanding estimate is scoped to current-period posted invoice value less posted allocations and is not a complete receivables ledger.

No tables or EF migration were required for this source-read-only subset. No build or test execution is available. `database/scripts/P1-M15/` only registers the module and view permission after source migrations.
