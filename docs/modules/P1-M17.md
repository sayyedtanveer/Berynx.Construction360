# P1-M17 Promotion and catalogue — implementation status

Updated: 2026-11-26. **Status: PARTIAL.** This document records the subset currently implemented; it does not claim full BRD acceptance or provider-backed delivery.

## Implemented slice

- Authenticated tenant management endpoints are registered by `Program.cs` through `MapM17` under `/api/v1/m17`.
- Catalogue list/save and consent list/save use tenant-scoped EF entities. Writes record `M17PromotionEvent`; API authorization checks M17 entitlement and endpoint-specific permissions.
- The public catalogue read endpoint checks tenant subscription and M17 entitlement, returns only published active products without customer-specific data, and is rate-limited by client IP.
- Angular `m17/promotion` uses shared `ApiClient`, server-side route licence/permission guard, M03 products/contacts lookups, loading/error/success states, catalogue filtering/edit/save, consent capture/opt-out and consent list refresh.
- Optional module/permission catalogue SQL seed does not grant M17 entitlements to any tenant.
